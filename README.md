# TAWASOL — تواصل v2
واجهة عربية HTML/CSS/Vanilla JS مع Backend Node.js وقاعدة SQLite دائمة.
تسجيل فعلي بالبريد وكلمة المرور بدل اختيار حساب تجريبي.

## التشغيل
يتطلب Node.js 24 أو أحدث، بلا حزم خارجية:
```sh
npm start
```
افتح http://localhost:8000 بالضبط، لأن حماية Origin ترفض المصادر الأخرى.
البيانات في data/tawasol.sqlite. لا ترفع مجلد data أو ملفات قواعد البيانات إلى GitHub.
الجداول تُهيأ عند بدء تشغيل الخادم، دون أي حسابات أو كلمات مرور افتراضية.

## تعيين مالك المنصة
سجّل حسابك من الواجهة أولًا، ثم نفّذ على الخادم بصلاحية مالكه:
```sh
node server/admin.mjs owner@example.com
```
سجّل الدخول مجددًا. لا يترقى أول حساب تلقائيًا، ولا يقبل API دورًا أثناء التسجيل.
يستطيع المالك ترقية حسابات مسجلة إلى Admin ومنح صلاحيات users/content/reports.
تعطيل المستخدم يبطل جميع جلساته فورًا.
الحذف النهائي للحسابات غير مفعّل في هذه النسخة؛ استعمل التعطيل.

## النشر
GitHub يخزن الكود. GitHub Pages وحده لا يشغّل Backend.
استخدم خادم Node 24 بقرص دائم مع reverse proxy يعمل بـ HTTPS.
الخادم يستمع على 127.0.0.1؛ يوجه الوكيل الطلبات إليه على الجهاز نفسه.
اضبط:
```sh
NODE_ENV=production
PUBLIC_ORIGIN=https://your-domain.example
PORT=8000
DATA_DIR=/absolute/private/persistent/path
```
PUBLIC_ORIGIN بلا شرطة مائلة أخيرة ويجب أن يطابق رابط الواجهة.
في الإنتاج تُرسل كوكي الجلسة مع Secure، فتحتاج HTTPS فعلًا.
لا تعرض منفذ Node مباشرة على الإنترنت. يمر وصول المستخدمين بالوكيل.
يجب أن تكون الواجهة وAPI على الأصل نفسه؛ لا ترفع الواجهة وحدها ثم تتوقع اتصالها بالخادم.
نسخ SQLite الاحتياطي يجب أن يشمل WAL بطريقة متسقة، ويفضل SQLite backup API.
هذا الإصدار مناسب لخادم واحد وحجم أولي؛ لا تشغّل عدة نسخ متوازية بملف مشترك.

## الوظائف
منشورات وصور وتعليقات وإعجاب ومتابعة ورسائل خاصة وإشعارات ومجتمعات وبلاغات.
صور بحد أقصى 1.5MB في الواجهة، وفحص نوع data URL وحجمها في الخادم.
الأدوار تُفحص في كل عملية على الخادم، وليست في الواجهة فقط.
الغرف حتى 5 أعضاء، واختيار الفيديو للمضيف، والدردشة للأعضاء.
تحديث الدردشة كل 5 ثوانٍ. مزامنة توقيت التشغيل بين المشاهدين ليست مطبقة.
لا توجد دعوات خاصة للغرف بعد؛ المستخدمون المسجلون يستطيعون رؤية قائمة الغرف والانضمام إذا لم تكتمل.

## الاختبارات
```sh
npm test
```
تتحقق من المصادقة وCSRF وOrigin والصلاحيات وعزل الرسائل وحد الغرف وإبطال الجلسات وتجزئة كلمات المرور.

راجع SECURITY.md قبل الإطلاق العام. رابط معاينة النموذج السابق لا يشغّل هذا الـBackend.

## تحديث v3 — الهوية والخصوصية والصوت
هوية برقوق ولايم وكورال مع وضع نهاري عاجي وافتتاحية قصيرة وتأثير ماوس وتقليل الحركة.
صفحة الرسائل أصبحت بقائمة محادثات وفقاعات وحالات تسليم وقراءة ومؤشر كتابة من الخادم.
الأسماء ليست دليلًا عامًا: البحث بالاسم من حرفين يعرض بيانات محدودة، والمتابعة المتبادلة تفتح المنشورات والتراسل.
إلغاء المتابعة يمنع مشاهدة المنشورات الجديدة والقديمة، ويوقف إرسال رسائل جديدة. تبقى المحادثة السابقة لطرفيها.
الحظر يلغي المتابعة ويمنع البحث والمتابعة والتراسل بين الطرفين.
للإدارة المصرح لها استثناء لمراجعة المحتوى. الغرف والمجتمعات مساحات منفصلة عن منشورات الأصدقاء.

الصوتيات:
- موسيقى على صورة: رفع ملف تملك حق استخدامه، اختيار البداية والمدة حتى 30 ثانية.
- يحول المتصفح المقطع إلى WAV أحادي القناة ويخزنه الخادم في جدول media.
- التسجيل الصوتي: حتى دقيقتين، إيقاف ومعاينة وإلغاء وإرسال وسرعات تشغيل.
- يتطلب التسجيل إذن الميكروفون وHTTPS أو localhost.
- الخادم يتحقق من بنية WAV PCM ومعدل العينات والحجم والمدة.
- ملفات الموسيقى لا تُفتح إلا لمن يملك صلاحية مشاهدة المنشور، والتسجيلات لطرفي المحادثة فقط.
- لا يوجد تشغيل تلقائي أو كتالوج أغانٍ تجارية أو اتصال بخدمة موسيقى.
- تحديث الرسائل كل 4 ثوانٍ، وليس WebSocket، ومزامنة توقيت فيديو يوتيوب لم تضف بعد.
- مرجع الأنيميشن بصري فقط؛ التنفيذ Vanilla دون React أو مكتبات إضافية.
- لم يُختبر ميكروفون فعلي في المتصفح الآلي؛ اختُبر مسار الصوت وصلاحياته على API.
